# Evaluation output

Generated retrospective matching, scoring and ensemble artifacts are written
to season-specific directories below this path. They are reproducible from the
merged model submissions and fixed outcome data.

The committed `2025-2026/` artifacts contain the six permanent `hubdemo`
baseline models and the regularized QRA built from them. These files are public
data products intended to support the hub's future demonstration website. They
include point-model scores, QRA WIS and interval coverage, and will be
regenerated when models or evaluation methods change. They also contain the
probabilistic normal-MA3 baseline and paired QRA-versus-baseline WIS skill and
coverage results used by the dashboard.
